What git status showed about the ignored files:

Why committing secrets is dangerous:
Secrets such as API keys can give unauthorized people access to systems or services. Once a secret is committed to a repository, it may remain in Git history even after the file is deleted. This can create security and financial risks, so sensitive values should never be committed to source control.
